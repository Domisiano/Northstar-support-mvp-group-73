# PROJECT CHARTER

## Project Title
Centralized Customer Support Chatbot

## Purpose
To develop a chatbot that helps customers check order, delivery,
return, and refund information from a centralized database.

## Scope
- Order tracking
- Delivery status
- Refund and return status
- Centralized transaction data
- Human support fallback

## Technical Stack
- HTML
- JavaScript
- JSON

## Team Responsibilities

- **Member 1 — UI Designer:** Dashboard and user interface
- **Member 2 — Data Engineer:** Central transaction database
- **Member 3 — Order Status Developer:** Order tracking functionality
- **Member 4 — Returns Developer:** Refund and return functionality
- **Member 5 — Mr. Elvisio (Admin):** Project coordination, charter,
  fallback routing, and service escalation

## Working Rules
- Every task must have an owner and clear completion criteria.
- Members must update task status and communicate blockers.
- Team synchronization is held at **9:00 PM EAT**.
- All changes must be committed through version control.
- Completed work must be tested before being merged.

## Definition of Done
A task is complete when the work functions correctly, is committed,
documented, and does not break existing functionality.

## Project Governance
All team contributions must be traceable through Git branches,
commits, pull requests, and project board updates.
